## Objective
What I want to build or understand.

## Concept link

## Steps
1. Create a Field Service Playground to training
2. Install the Managed Package for the necessary licenses and permissions
3. Build your team to create users and schedule the orders. 

## Result
A basic user for a technician external and the permissions for him. 

## What broke
**Error:** `INVALID_FIELD` when creating a Service Resource in Guided Setup.
**Message:** Only users with the "Field Service Scheduling" user permission can be included in scheduling optimization.

**Cause:** The technician user was missing two things: the resource permission set (I had only created the admin one in Guided Setup) and the required permission set licenses on the user record. Because the upsert failed, the Service Resource was never created, so nothing showed up in the Dispatcher Console.

**Fix:** Assign the missing licenses to the technician in Users, assign the resource permission set, and create the Service Resource again.

**Lesson:** A resource needs the right license AND the right permission set. Check both layers, in that order, and read the error literally.

## What I learned
All teams are users but not all users are a team, technician, dispatcher, etc.
Permissions, licenses and permission set are different terms, and all are important for differente users.
